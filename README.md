## Making new theme example

This folder on an orphan branch is intended to be used to produce consistent theme examples.

1. Be sure your new theme is on the master branch.
1. Get this branch locally.
1. Create somewhere on your local machine a folder where you will run the `Exercise Handler` setup choosing the theme you want  to create an example of.
1. Get from this branch the `Fermat.tex` and the `Solitary.tex` exercises with which you should create an exercise sheet.
1. Convert the exercise-sheet `PDF` file to a `png` e.g. [here](https://pdf2png.com/).
1. Add the png file to the orphan branch, commit it and push.
1. Update the `README` file on the master branch.
